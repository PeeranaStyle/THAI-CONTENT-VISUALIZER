# Project goal

Build Thai Content Visualizer as a production-oriented learning workspace using Next.js App Router, TypeScript, Tailwind CSS, Supabase PostgreSQL and Storage, custom username/password sessions, and KKU IntelSphere. Prioritize a genuinely working Thai-content quiz workflow, then graph exploration, notes, and learning analytics. Keep integrations server-side, never expose quiz keys early, and report any external dependency that cannot be verified without credentials.

## Acceptance

Follow the complete definition of done in the user's master implementation brief. The goal remains active until functionality, security, responsive behavior, production build, and end-to-end verification are complete or a specific external prerequisite prevents further verification.
